# 18. immigration Code of Conduct
(1) An immigration consultant shall, in consultancy, be bound by the Code of Conduct set out in the Second Schedule.
(2) An immigration consultant who carries out the immigration consultancy contrary to the provisions of the Code offence and is liable, upon conviction, to a fine not exceeding one hundred thousand penalty units or to imprisonment for a period not exceeding twelve months, or to both. 17th May, 2013 Statutory Instruments
